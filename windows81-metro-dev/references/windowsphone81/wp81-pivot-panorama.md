# Windows Phone 8.1 Pivot And Panorama

Use this when choosing phone navigation controls.

## Panorama

Use Panorama when:

- The page is a broad home experience.
- Sections are content areas, not strict tabs.
- The app benefits from a wide, scenic horizontal sweep.

Rules:

- Keep each section lightweight.
- Avoid heavy interactive controls in every section.
- Use it for orientation and discovery, not dense task execution.

## Pivot

Use Pivot when:

- Sections are peers with similar weight.
- Users switch frequently between filters, categories, or states.
- Each section can be understood as a tab-like slice.

Rules:

- Keep headers short.
- Avoid nesting Pivots.
- Avoid horizontal gestures inside Pivot content that conflict with Pivot swipes.

## Mapping

- Windows HubPage with broad sections maps to Panorama.
- Windows SectionPage with peer categories maps to Pivot or ListPage.
- Windows SemanticZoom usually maps to Pivot, jump list, search, or filters.
