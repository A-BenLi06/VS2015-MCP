# Windows Phone 8.1 Small Screen Density

Use this for phone information density.

## Density Rules

- Show the title, primary value, and one or two secondary fields.
- Move heavy metadata to detail pages.
- Use collapsed sections for rarely needed detail.
- Prefer one-column list rows.
- Avoid dense tables and multi-pane layouts.

## Forms

- Put primary save/accept in ApplicationBar.
- Keep fields in vertical order.
- Group related fields with headings.
- Avoid side-by-side controls unless they are very short and obvious.

## Search

- Prefer a dedicated SearchPage or a focused in-page search box.
- Results should be single-column.
- Filters should be lightweight and easy to dismiss.

## Glanceability

- Use readable titles.
- Keep line lengths short.
- Do not overload list rows with status chips, buttons, and metadata.
- Prioritize the next likely user action.
