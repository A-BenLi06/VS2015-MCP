# Windows Phone 8.1 ApplicationBar

Use this for phone command placement.

## Placement

- Primary actions: bottom ApplicationBar icon buttons.
- Secondary actions: ellipsis menu.
- Destructive or rare actions: ellipsis menu plus confirmation when needed.

## Primary Actions

Good icon candidates:

- add.
- save.
- accept/check.
- refresh.
- search.
- edit.

Keep the primary icon set small and task-focused. Do not fill the bar with every possible command.

## Secondary Actions

Good menu candidates:

- delete.
- sort.
- filter.
- pin.
- share.
- settings.
- clear.

## Do Not

- Do not create custom persistent bottom toolbars by default.
- Do not place many tiny action buttons inside list rows.
- Do not map Windows 8.1 AppBar groups one-to-one onto the phone bar.
