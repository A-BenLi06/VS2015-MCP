# Shared Metro Principles

Use this for both Windows 8.1 Store and Windows Phone 8.1.

## Shared Language

Both targets share:

- Content before chrome.
- Strong typography.
- Touch-first interaction.
- Sparse, high-confidence accent color.
- Platform command surfaces.
- Fast, direct, spatial motion.
- Async data loading and explicit loading/error/empty states.

## Different Grammar

Do not confuse shared design language with shared layout:

- Windows 8.1 Store is horizontal information architecture.
- Windows Phone 8.1 is vertical task flow.
- Shared product intent should become platform-specific page composition.

## Visual Rules

- Use type, grouping, and spacing as hierarchy.
- Avoid gradients, glass, skeuomorphic decoration, heavy borders, heavy shadows, and web-card chrome.
- Use one or two accent colors.
- Keep imagery content-bearing.
- Keep commands off the main canvas unless the task requires constant access.
