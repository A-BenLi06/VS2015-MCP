# Layout Grid

Use this for spacing, canvas structure, and information hierarchy.

## Windows 8.1 Store

- Treat the app as a wide content canvas.
- Prefer a large page title at the left, then horizontal content sections extending right.
- Use grouped sections instead of deep menu trees.
- Let important content occupy real space; avoid framing everything in cards.
- Use multi-column layouts when width supports scanning.
- Keep command chrome at the edges or hidden until invoked.

Common page rhythm:

```text
large page title
section header     section header     section header
tile tile tile     tile tile tile     list/list/list
tile tile tile     tile tile tile
```

## Windows Phone 8.1

- Treat the app as a vertical one-hand task flow.
- Prefer one primary content column.
- Use Pivot or Panorama headers for horizontal section movement.
- Keep visible metadata selective: title, primary value, one or two secondary fields.
- Move heavy metadata to detail pages or collapsed sections.

## Spacing

- Use spacing to group content before adding borders.
- Use whitespace more generously on Windows 8.1 than WP8.1.
- Keep phone spacing tight enough for glanceability, but never cramped.
- Align section headers, item edges, and command surfaces predictably.

## Do Not

- Do not put page sections inside floating cards.
- Do not use dense desktop table layouts as a main visual pattern.
- Do not fill a wide Windows page with a narrow phone column.
- Do not make a phone screen imitate a Windows SplitPage.
