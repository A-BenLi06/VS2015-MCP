# Accessibility And Touch

Use this for touch-first UI and keyboard/mouse compatibility.

## Touch First

- Make primary targets comfortably finger-sized.
- Avoid tiny inline buttons scattered through content.
- Do not depend on hover.
- Do not require right click or edge gestures as the only path to primary actions.
- Keep phone primary actions reachable from the bottom ApplicationBar.

## Keyboard And Mouse

- Provide keyboard focus order for forms, lists, and commands.
- Support mouse selection and context invocation where appropriate.
- Keep visible focus states.
- Ensure AppBar/ApplicationBar commands have labels or accessible names.

## Back And Transient UI

- Windows Phone Back should close transient UI before navigating away.
- Windows 8.1 pages may include explicit back affordances when appropriate.
- Do not duplicate every phone Back action with a large visible back button.

## Readability

- Use sufficient contrast.
- Avoid putting key text over busy images without a solid treatment.
- Keep text from overlapping AppBars, system UI, and snapped/narrow layouts.
- Use typography and spacing before borders.
