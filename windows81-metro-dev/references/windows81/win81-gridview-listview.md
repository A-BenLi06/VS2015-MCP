# Windows 8.1 GridView And ListView

Use this for Windows Store collection pages.

## Choose GridView

Use GridView for:

- Photos.
- Products.
- Albums.
- Files with thumbnails.
- Travel destinations.
- Courses.
- Visual dashboards.

## Choose ListView

Use ListView for:

- Messages.
- Tasks.
- Search results.
- Routes.
- Settings entries.
- Logs and activity.
- Text-heavy records.

## Grouping

- Use grouped data when users scan categories.
- Keep group headers clear and actionable when they navigate.
- Show 3 to 8 representative items per HubPage section.
- Provide a SectionPage for complete group exploration.

## Item Template

- Use primary title.
- Add one strong visual or status cue.
- Add one or two secondary metadata fields.
- Avoid web-style card borders and shadows.

## States

Implement loading, empty, error, stale/offline, and selected states.
